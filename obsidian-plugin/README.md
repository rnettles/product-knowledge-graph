# Product Knowledge Graph Workbench for Obsidian

Documentation-first project for a profile-driven Obsidian plugin that helps users navigate and
manage a Product Knowledge Graph documentation estate.

The workbench combines two related experiences:

- a **Documentation Command Center** that recommends and explains the next most valuable
  documentation action;
- an **Estate Explorer** for navigating collections, subjects, traceability, facets, maturity
  rungs, and estate health.

The plugin is intended to support any compatible Product Knowledge Graph project profile. MBS is
the first reference project and must remain configuration rather than plugin-specific behavior.
